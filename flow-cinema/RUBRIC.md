# RUBRIC — honest scoring of a flow-cinema film (/48)

Watch real rendered frames before scoring. No inflation. List ≥2 weaknesses every time.
A film with a hard-fail defect cannot score above 24. **Engagement cap (see bottom) is the
defect that caught the bland A1** — technical polish is the floor, not the goal.

| # | Dimension | /pts | What full marks looks like |
|---|-----------|------|----------------------------|
| 1 | **Character consistency** | 8 | Protagonist's face/hair/wardrobe read as the SAME person across every shot. Cast via 角色. Drift = signature failure; ≤4 if hair/face changes between shots. |
| 2 | **Clean frame (no garbled text)** | 6 | Zero model-rendered letters/signs/captions. Any gibberish pseudo-text = hard fail (cap 24). |
| 3 | **Style fidelity & coherence** | 6 | Every shot reads as one film — same style, grade, lighting, aspect, model tier. |
| 4 | **Cinematic craft (sub-rubric, 3×2)** | 6 | (a) 景别 rhythm/coverage: ≥3 sizes/scene, no two identical 景别 back-to-back, a wide always paid off by a CU; (b) motivated + NON-repeating camera move, power beats use paired low/high angles; (c) composition/light/depth: 留白, off-center smallness, foreground/mid/back layering. Each sub-item /2. |
| 5 | **Narrative beat (9-act)** | 6 | The act delivers its framework function (e.g. A3 = irreversible turn + 觉悟 + 誓言); shots assemble into a real arc with a payoff. |
| 6 | **ENGAGEMENT — would a viewer keep watching? (5 sub-scores)** | 8 | see breakdown below |
| 7 | **Concept originality** | 4 | Fresh premise/mashup, not a generic montage. Honors the diversity rule. |
| 8 | **Audio/narration plan** | 4 | Clips carry clean ambient (or PROVEN voiced 角色 dialogue); single-voice narration + BGM plan exists for post. |

### Dimension 6 — ENGAGEMENT /8 (the layer A1 was missing)
- **Hook strength** (0-2): 0 = opens on an empty establishing wide; 1 = a focal subject but no question; 2 = a DETAIL/CONFLICT that plants a question in the first 3s.
- **Character moment** (0-2): 0 = no CU/no character; 1 = present but passive or late (>30% in); 2 = an intimate CU/MCU with a readable emotion, early.
- **Dramatic tension / show-don't-tell** (0-2): 0 = theme only narrated; 1 = implied; 2 = theme STAGED visually (contrast / paired angles / conflict in frame).
- **Visual rhythm** (0-1): 0 = all flat 8s equal cuts; 1 = planned trim/length variation or a tension→release curve.
- **"Would a viewer keep watching"** (0-1): holistic gut check after watching it once.

**Scoring ritual:** open ≥1 variant of every shot (or extract frames). First run the DESIGN gate
(the 5 contract items in `references/CINEMATIC-CRAFT.md §1`) retroactively; THEN score each
dimension with one concrete reason; sum. Compare to the best film in LEDGER. If the user supplies
real engagement numbers, log them in state and let them outweigh this rubric.

**Hard fails (fix before the film counts as delivered) — cap total at 24:**
- garbled on-screen text in any kept clip
- the lead is visibly a different person between shots
- a kept clip is broken/black/wrong-aspect

**ENGAGEMENT CAP (the A1 catch) — cap total at 28/48:**
- An act with NO close-up/MCU on a character AND no opening hook is dramatically inert; it cannot
  exceed **28/48** no matter how clean, consistent, or pretty every clip is. Run the DESIGN gate;
  an act that wouldn't pass the gate hits this cap. (Bland-but-technically-perfect = failure.)
